# WinCrack 🛠️

**WinCrack** is a lightweight, low-footprint utility designed for Windows Preinstallation Environments (WinPE). It provides system administrators and technicians with offline system maintenance capabilities, administrative access recovery, and environment troubleshooting tools directly from a bootable ISO.

Currently WinCrack has the ability to swap sethc.exe (Sticky keys) for cmd.exe (command prompt) meaning you can press shift 5 times to open a command prompt, doing so on the Windows lock screen gives you SYSTEM level privileges to modify files and user attributes without limit  
(Tip: use command "netplwiz" to easily manage Users without loging in or having administrator priviliges)  
It also includes the original TASKMGR from 1996 in place of utilman.exe (accesibility shortcut) as it is lightweight and unrestricted (can kill unkillable procceses)
